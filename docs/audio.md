# Оцифровки винила: загрузка, скачивание, мини-плеер

Входит в основной проект. Ниже — что умеет модуль и что настроить на сервере при установке или обновлении.

## Что появилось

**Админка, редактирование пластинки.** У каждого сохранённого трека есть иконка загрузки. Файл уходит на сервер сразу, без сохранения формы, а ход загрузки показывается в процентах. После загрузки в строке видны формат и размер, а также кнопки замены и удаления. Над трек-листом показано имя папки и кнопка «Удалить папку целиком».

- Поддерживаются FLAC, WAV и MP3. Формат проверяется по сигнатуре файла: переименованный `.txt` или MP3 с расширением `.flac` будет отклонён.
- Первая загрузка создаёт папку `public/uploads/music/Имя_Исполнителя_-_[год]_-_Название_Альбома`. Год берётся из «Год альбома», а если поле пустое, из «Год издания»; без года будет `Имя_Исполнителя_-_Название_Альбома`.
- Файл сохраняется как `XX_Название_Трека.ext`, где `XX` — порядковый номер трека в сохранённом трек-листе: `01`, `02` и т.д.
- Пробелы заменяются на `_`, символы `/ \ : * ? " < > |` и подобные удаляются. Кириллица сохраняется.
- Замена файла удаляет старый файл. Удаление последнего файла удаляет пустую папку.
- Если убрать строку трека с оцифровкой и сохранить форму, файл удаляется с диска; перед этим появится предупреждение. При удалении пластинки удаляется и её папка с музыкой.
- У новых, ещё не сохранённых строк вместо иконки написано «Загрузка после сохранения»: файл привязывается к ID трека в БД.

**Публичная карточка.** У треков с оцифровкой появляются кнопки «слушать» и «скачать». При воспроизведении под названием трека открывается мини-плеер с ползунком перемотки и временем. После окончания трека автоматически включается следующий трек с оцифровкой.

**Данные.** Ссылка на файл хранится в `record_tracks.audio_path`, вместе с форматом, размером и датой загрузки. Имя папки хранится в `records.music_dir`. Диск не сканируется: наличие оцифровки определяется только по БД.

**Ссылка для скачивания** — `/download.php?track=ID`. Скрипт отдаёт файл с корректным UTF-8 именем через `Content-Disposition`, поэтому кириллическое имя сохраняется. Этой ссылкой можно делиться. Плеер берёт файл напрямую из `/uploads/music/...`, чтобы перемотку через Range-запросы обслуживал веб-сервер.

Если позже изменить название или порядок трека, файл на диске не переименуется: ссылка в БД остаётся прежней. Чтобы получить новое имя, загрузите файл заново.

## Установка

### 1. Резервная копия

```bash
cd /var/www/vinyl-catalog
tar czf ~/vinyl-catalog-before-audio-$(date +%F).tgz app public/admin public/assets public/*.php
mysqldump vinyl_catalog > ~/vinyl_catalog-before-audio-$(date +%F).sql
```

### 2. Миграция БД

Миграция только добавляет колонки и индекс, существующие данные не меняются. Повторный запуск безопасен.

```bash
mysql vinyl_catalog < sql/04_track_audio.sql
```

### 3. Файлы

При обновлении существующей установки скопируйте `app/`, `public/`, `sql/` и `tests/` из репозитория в корень проекта (например, `/var/www/vinyl-catalog`), не трогая `app/config.php` и `public/uploads/`.

| Файл | Статус |
| --- | --- |
| `app/audio.php` | новый |
| `app/track_editor.php` | изменён |
| `app/tracks.php` | изменён: возвращает ссылки удалённых треков |
| `public/admin/edit.php` | изменён |
| `public/admin/track_audio.php` | новый: загрузка и удаление |
| `public/download.php` | новый |
| `public/record.php` | изменён |
| `public/assets/css/gallery.css` | изменён |
| `public/assets/js/site.js` | изменён |
| `public/uploads/music/.htaccess` | новый: MIME-типы для Apache |
| `sql/04_track_audio.sql` | миграция |
| `tests/audio_test.php` | тест |

`app/config.php`, фотографии и остальные файлы не трогаются.

### 4. Папка и права

```bash
mkdir -p /var/www/vinyl-catalog/public/uploads/music
chown www-data:www-data /var/www/vinyl-catalog/public/uploads/music
chmod 775 /var/www/vinyl-catalog/public/uploads/music
```

Укажите пользователя PHP-FPM или Apache, если он отличается от `www-data`. Временная папка PHP (`upload_tmp_dir`, обычно `/tmp`) должна вмещать самый большой файл.

### 5. Лимиты загрузки

Без этих настроек будут загружаться только файлы до текущего лимита PHP: по умолчанию 2 МБ. Альбом во FLAC 24/96 может занимать 100–300 МБ на сторону, если сторона сохранена одним файлом.

**PHP** (`/etc/php/8.x/fpm/conf.d/99-vinyl-audio.ini` или пул FPM через `php_admin_value`):

```ini
upload_max_filesize = 2G
post_max_size = 2G
max_input_time = 900
max_execution_time = 900
```

**Nginx** (в `server {}` каталога):

```nginx
client_max_body_size 2G;

location ^~ /uploads/music/ {
    types { audio/flac flac; audio/wav wav; audio/mpeg mp3; }
    add_header X-Content-Type-Options nosniff;
}

# В location для PHP, или отдельно для этого скрипта:
# fastcgi_read_timeout 900s;
```

`^~` нужен, чтобы regex-location для `.php` не применялся внутри папки с музыкой.

**Apache:** с версии 2.4.53 `LimitRequestBody` по умолчанию равен 1 ГБ. Если файлы больше, добавьте в vhost:

```apache
LimitRequestBody 2147483648
# при mod_fcgid также: FcgidMaxRequestLen 2147483648
```

MIME-типы для Apache задаёт `uploads/music/.htaccess` из репозитория. Запрет выполнения PHP наследуется из существующего `uploads/.htaccess`.

После изменений: `systemctl reload php8.x-fpm nginx` или `apache2`.

### 6. Необязательно: отдача через Nginx

Чтобы `download.php` не передавал файл через PHP, а только проверял ссылку в БД, добавьте в `app/config.php`:

```php
const AUDIO_X_ACCEL = true;
```

Тогда Nginx отдаст файл сам, с поддержкой докачки. Для Apache это не нужно: используется обычная передача через PHP.

Лимиты можно переопределить в `config.php`:

```php
const MAX_AUDIO_UPLOAD_SIZE = 3 * 1024 * 1024 * 1024; // по умолчанию 2 ГБ
const MUSIC_DIR = '/var/www/vinyl-catalog/public/uploads/music'; // по умолчанию
```

## Проверка после установки

```bash
php tests/audio_test.php
```

1. Откройте редактирование любой пластинки: у треков должна появиться иконка загрузки.
2. Загрузите короткий MP3: появятся папка `uploads/music/...`, файл `01_...mp3` и строка «MP3 · N МБ».
3. Откройте карточку без входа: появятся кнопки «слушать» и «скачать», мини-плеер должен проигрывать и перематывать.
4. Удалите файл, затем проверьте «Удалить папку целиком».

Если иконок нет и появилось сообщение о миграции, значит, `sql/04_track_audio.sql` ещё не применён.

## Что проверено локально

PHP 8.5, MariaDB 11.8, Chromium, на копии проекта и дампа:

- загрузка FLAC, WAV и MP3, создание папки и имён файлов, замена файла с удалением старого;
- отклонение текстового файла с расширением `.flac` и MP3 с расширением `.flac`;
- удаление одного файла и папки целиком; удаление файла при удалении строки трека и сохранении формы;
- старые записи вида «A1 - Название - 7:41»: в имя файла попадает только название;
- воспроизведение, пауза, перемотка, автопереход к следующему треку и скачивание с UTF-8 именем;
- 401 без входа и 403 без CSRF-токена для `track_audio.php`;
- повторный запуск миграции; телефон 375 px, планшет и широкий экран без горизонтального переполнения;
- каталог, добавление пластинки, сохранение трек-листа и 42 существующих теста треков.
